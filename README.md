# Cigar Box Design Simulator

ファミマ・ローソンのシール紙印刷向けの、印刷データ作成ツールです。
画像を読み込むと、箱に貼った仕上がりを確認でき、カット線入りの印刷用PNG（解像度情報つき）を保存できます。
ブラウザだけで動き、ビルドもサーバーも不要です。`index.html` 1ファイルで、GitHub Pages にそのまま置けます。

## 使い方

1. 画像を読み込む（画像を選択 / ドラッグ&ドロップ / 貼り付け / SVG コードの貼り付け）
2. 箱のサイズ（きぞはこ・かずはこ）とサイドテープを選ぶ
3. 「プレビュー（平面・立体・3箱）」で、貼った見え方を確認する
4. 必要なら「画像の縦横比」を「はこに合わせる」にして、画像を引き伸ばす
5. 「印刷用」モードでカット線を確認し、「印刷用PNGを保存」

- 読み込める画像：PNG / JPEG / WebP / SVG（SVG は長辺 4200px の画像に変換して扱います）
- 画像・設定はブラウザに自動保存されます（`IndexedDB` / `localStorage`）。
  iOS Safari はホーム画面に追加していないサイトの保存データを、長期間使わないと消すことがあります。
  設定は画面の数項目だけなので、消えても再設定は簡単です。

## パラメータ

画面でいじれるのは次だけです。`index.html` の `PARAMS` が定義で、UI の自動生成・検証・保存がすべてここから行われます。

| グループ | key | 内容 | 初期値 |
|---|---|---|---|
| 箱 | `box` | `kizo`（きぞはこ 180×120×60mm）/ `kazu`（かずはこ 165×120×60mm） | `kizo` |
| サイドテープ | `sideTape` | サイドテープ（白テープ枠）を貼る | オン |
| | `tapeWidth` | テープの幅（mm） | 6 |
| 画像の縦横比 | `artFit` | `asis`：サイズそのまま（画像の物理サイズのまま中央に置く。PNG/JPEG は 300dpi 相当、SVG は viewBox の 1 単位 = 1mm。箱を切り替えても絵の大きさは変わらず、はみ出しは切れ、足りない所は白い余白になる）/ `fit`：はこに合わせる（選択中の箱のカット後サイズに引き伸ばす）。どちらも残る範囲の中央に合わせる | `asis` |
| 出力設定 | `printGuide` | 印刷用 PNG にカット線を入れる | オン |

### 表示モード（プルダウンで選択）

- プレビュー（平面）：貼り付け先を正面から見た図
- プレビュー（立体）：斜めから見た箱1つ
- プレビュー（3箱）：立体の箱を3つ、ぴったりくっつけて並べた図
- 印刷用：用紙 178×127mm にカット線を入れた図（PNG の書き出し対象）

プレビューの枠は固定です。かずはこ（165mm）はきぞはこ（180mm）より、枠の中で小さく表示されます。

### 固定仕様

| 項目 | 値 |
|---|---|
| 用紙 | 178×127mm（コンビニのシールプリント） |
| 貼り付け先の高さ・奥行き | 120mm / 60mm |
| 下側のカット幅 | 10mm（一旦固定。カット後 117mm ＝ 貼り付け先 − 余白 3mm） |
| 右側のカット幅 | きぞはこ：なし ／ かずはこ：16mm（`BOXES.cutRight`） |
| サイドテープの色 | 白 |
| 余白の色・箱の地の色 | 白 / `#cbd5e1` |
| 解像度 | 300dpi（印刷用）／ 200dpi（プレビュー PNG） |
| 画像の位置調整 | 一旦なし（`offX` / `offY`。優先度低。必要になったら `PARAMS` に追加） |

#### かずはこのカット

かずはこ（幅 165mm）は余白 3mm 固定とし、カット後の幅を 162mm（165 − 3）にします。
用紙 178mm から 16mm を、**右側だけ**切ります。下は 10mm（きぞはこと同じ）です。
カット線は下と右の2本になります。切る側や余白の考え方は、`index.html` の `BOXES` のコメントにある通り後で見直します。

カット後の用紙は、貼り付け先の中央に貼るものとして計算します。

## 公開（GitHub Pages）

リポジトリの Settings → Pages で、ブランチ `main` / ルートを公開元にすると
`https://<ユーザー名>.github.io/cigar-box-design-simulator/` で使えます。
画像はブラウザ内でしか処理されず、サーバーには送られません。

## ロードマップ
