# Cigar Box Design Simulator

ファミマ・ローソンのシール紙（178×127mm）で、シガーボックスに貼るシールを作るツールです。
ブラウザだけで動き、ビルドもサーバーも不要です。GitHub Pages にそのまま置けます。

## 構成

役割ごとにページ（URL）を分けています。

| パス | ページ | 内容 | AI による編集 |
|---|---|---|---|
| `/` | 入口 | 2つのページへのリンク | しない |
| `/preview/` | 仕上げ・確認 | 画像や SVG を読み込み、箱に貼った仕上がりを確認して印刷用PNGを保存する | しない（決定論的なコードのみ） |
| `/draft/` | デザイン微調整（テンプレート） | このページの依頼文をコピーして AI に渡し、参考画像をもとにした自分用の調整ツールを作る | AI が作る調整ページは、**スロット**（`PARAMS` と `draw`）だけ書く。画面の固定部分は共通スクリプトが作る |
| `/shared/` | 共通部分 | 箱の仕様・カット計算・プレビュー描画（`box.js`）、調整ページの固定部分（`draft-app.js`）、スタイル（`style.css`） | しない |
| `/docs/ai-guide.md` | AI 向けガイド | 調整ページの作り方と、SVG のルール | - |
| `/examples/` | 見本 | 複雑なデザイン（波）をコードで生成する例（`generate-waves.mjs`） | - |

デザインは **箱の面と同じサイズ**（きぞはこ 180×120mm / かずはこ 165×120mm）で作ります。
178×127mm の用紙への配置やカット線は、ツール側で決めます。

## 使い方

### デザイン微調整（テンプレート）（`/draft/`）

デザインは、参考画像として AI に渡します。このツールはデザインを作りません。

1. 「調整したい項目」を書いて「AIへの依頼文をコピー」を押し、参考画像と一緒に AI に送る
2. AI が、このページを元にした調整ページを作る（画像のデザインを SVG で再現し、項目を動かせるようにする）
3. 調整ページで調整して、「SVGを保存」する
4. 保存した SVG を、仕上げ・確認ページで読み込む

AI が作る調整ページは別のサイトになるため、仕上げ・確認ページへデータは直接渡せません。
保存した SVG を、仕上げ・確認ページにドラッグ&ドロップ（またはコードを貼り付け）で読み込みます。
SVG は 1 単位 = 1mm の、箱の面と同じ大きさにしてください（詳しくは [`docs/ai-guide.md`](docs/ai-guide.md)）。

このページ自体にも、サンプルのデザイン（図形を規則的に並べたもの）があり、そのまま動きます。

- 「SVGを保存」「SVGをコピー」：いまの調整値を反映した SVG を保存・コピーする。AI に渡して手直しを頼むときにも使える
- 「PNGで保存」：同じデザインを 300dpi の PNG で保存する（スマホで写真に入れる用）
- 「仕上げページを開く」（別ウィンドウ）：このデザインを持って、仕上げ・確認ページを開く。同じサイトなら直接渡せる。別のサイトなら SVG をコピーしてから開くので、仕上げ・確認ページに貼り付ける

#### スロット（`PARAMS` と `draw`）

AI が作る調整ページは、`AI-SLOT:BEGIN` 〜 `AI-SLOT:END` の中だけを書きます。
それ以外（見せ方の切り替え・箱の切り替え・サイドテープ・プレビュー・出力ボタン）は、`shared/draft-app.js` の `CigarBox.mountDraft({ PARAMS, draw })` が作ります。
AI が自作しないので、「サイドテープが抜ける」「プレビューが固定されない」といったばらつきが出ません。

- 余白の設定は、この画面にはありません（仕上げ・確認ページで決めます。微調整中は初期値の 3mm で表示します）
- サイドテープの設定（貼るか・色・左右上下の幅・連動）は、仕上げ・確認ページと共通です。同じブラウザで片方を変えると、もう片方にも反映されます（共通の保存先：`localStorage` の `cigar-box-sim:tape`）
- 依頼文には、サイドテープの現在の設定が `tape: { ... }` として入ります。AI が作るページは別のサイトで動くため保存データを共有できませんが、この値が初期値になるので、依頼文をコピーするたびに最新の設定が引き継がれます。AI が作ったページで変えた設定は、そのページ（そのブラウザ）に保存されます

- `PARAMS`：画面に出す調整項目の配列
- `draw(box, p)`：デザインの SVG の中身（`<svg>` の中に入る要素）を文字列で返す関数。座標は箱の面（1 単位 = 1mm）

契約の詳細は `draft/index.html` 冒頭のコメントと [`docs/ai-guide.md`](docs/ai-guide.md) にあります。
複雑なデザイン（波など）は `draw` の中で JavaScript を使って自由に生成できます（見本：[`examples/generate-waves.mjs`](examples/generate-waves.mjs)）。

#### 安全性

このサイトは、他人のコードや SVG を **取り込んで実行する機能を持ちません**。

- `/draft/` は、コードや SVG を貼り付けて読み込む機能がありません。スロットのコードは、リポジトリに入っているものだけが動きます
- AI が作った調整ページは別のサイトで動くので、このサイトの保存データには触れません
- `/preview/` が読み込む SVG は、画像として変換して扱い、`script` などは取り除きます

### 仕上げ・確認（`/preview/`）

1. 画像を読み込む（叩き台から送る / 画像を選択 / ドラッグ&ドロップ / 貼り付け / SVG コードの貼り付け）。AI が作った調整ページで保存した SVG もここで読み込む
2. 箱のサイズとサイドテープを選ぶ
3. 「プレビュー（一箱・縦に並べる・横に並べる）」で、貼った見え方を確認する
4. 「印刷用」モードでカット線を確認し、「印刷用PNGを保存」（2102×1500px / 300dpi）

- スマホ（タッチ操作の端末）では、PNG の保存で共有メニューが開きます。iOS では「画像を保存」で写真に追加できます（「ダウンロード」だと「ファイル」アプリにしか入りません）
- 読み込める画像：PNG / JPEG / WebP / SVG（SVG は 300dpi 相当の画像に変換して扱います）
- 画面には画像を `blob:` URL で表示し、長辺 2400px を超える画像は画面用だけ縮小します（PNG の書き出しには元の画像を使うので、仕上がりは変わりません）
- 画像・設定はブラウザに自動保存されます（`IndexedDB` / `localStorage`）。
  iOS Safari はホーム画面に追加していないサイトの保存データを、長期間使わないと消すことがあります。

#### 設定項目

| グループ | key | 内容 | 初期値 |
|---|---|---|---|
| 箱 | `box` | `kizo`（きぞはこ 180×120×60mm）/ `kazu`（かずはこ 165×120×60mm） | `kizo` |
| サイドテープ | `sideTape` | サイドテープ（テープ枠）を貼る | オン |
| | `tapeColor` | テープの色（「貼る」と同じ行のカラーピッカー） | 白 |
| | `tapeX` | 左右のテープの幅（mm、0〜30、1mm 刻み） | 6 |
| | `tapeY` | 上下のテープの幅（mm、0〜30、1mm 刻み） | 6 |
| | `tapeLink` | 縦横を連動（ロック）。左右と上下の差を保ったまま、一緒に動く | オン |
| 余白 | `marginX` | 左右の余白（mm、0〜20、1mm 刻み）。両側の合計（片側はその半分）。きぞはこは最小 2mm | 3 |
| | `marginY` | 上下の余白（mm、0〜20、1mm 刻み）。両側の合計 | 3 |
| | `marginLink` | 縦横を連動（ロック）。左右と上下の差を保ったまま、一緒に動く | オン |
| 画像の縦横比 | `artFit` | `asis`：サイズそのまま（画像の物理サイズのまま箱の面の中央に置く。PNG/JPEG は 300dpi 相当、SVG は viewBox の 1 単位 = 1mm。はみ出しは切れ、足りない所は白い余白になる）/ `fit`：はこに合わせる（箱の面のサイズに引き伸ばす） | `asis` |
| 出力設定 | `printGuide` | 印刷用 PNG にカット線を入れる | オン |

箱・サイドテープ・余白の項目は `shared/box.js` の `BOX_PARAMS`（デザイン微調整ページは、そこから余白を除いた `DRAFT_BOX_PARAMS`）、それ以外は `preview/index.html` の `PARAMS` で定義しています。

#### 表示モード

プレビューは 3 つ（初期値は「一箱」）。プレビューの下のボタンで切り替え、スマホではプレビューと一緒に画面上部に固定される。どれも、右の側面と上面が見える向きの立体で、箱を回すと、見える面が入れ替わる。サイドテープを貼ると、側面はテープの色になる（cigar-box-design-lab の拡大表示と同じ見せ方）。

- プレビュー（一箱）：1 つの箱を、面の中で時計回りに 90 度ずつ回した 4 つ（2×2）
- プレビュー（縦に並べる）：箱を、長辺（180mm）どうしをくっつけて上に 3 つ積む。「全部同じ向き」と「真ん中の一つを 180 度逆に」の 2 つを左右に並べる
- プレビュー（横に並べる）：箱を、短辺（120mm）どうしをくっつけて横に 3 つ並べる。2 つの中身は上と同じ（上下に並べる）
- 印刷用（仕上がり確認）：用紙 178×127mm にカット線を入れた図（PNG の書き出し対象。仕上げ・確認ページのみ）。余白を反映した印刷イメージを確認でき、書き出す PNG は用紙の左上に詰めてカット線が入った形のまま

プレビューの枠は、「一箱」「縦に並べる」「横に並べる」のどれでも同じ大きさで固定です（「一箱」の大きさに合わせ、はみ出す分は縮めて中央に置く）。かずはこ（165mm）はきぞはこ（180mm）より、枠の中で小さく表示されます。

## 固定仕様（`shared/box.js`）

| 項目 | 値 |
|---|---|
| 用紙 | 178×127mm（コンビニのシールプリント） |
| 貼り付け先の高さ・奥行き | 120mm / 60mm |
| カット幅 | 余白から決まる（下記） |
| 余白の色・箱の地の色 | 白 / `#cbd5e1` |
| 解像度 | 300dpi（印刷用）／ 200dpi（プレビュー PNG） |
| 画像の位置調整 | 一旦なし（`offX` / `offY`。優先度低） |

カット後の用紙（シール）は、箱の面の中央に貼るものとして計算します。そのため、箱の面と同寸のデザインは、余白の分（初期値は片側 1.5mm）がシールに載りません。

- 上下：シールの高さ = 120 − 上下の余白。下側のカット幅 = 127 − シールの高さ（余白 3mm なら 10mm、0mm なら 7mm）
- かずはこ（幅 165mm）の左右：シールの幅 = 165 − 左右の余白。右側だけを切る（余白 3mm なら 162mm・右 16mm カット）
- きぞはこ（幅 180mm）の左右：用紙が 178mm なので、左右の余白は最小 2mm。0〜2mm の間は 2mm のまま（切らない）で、2mm を超えた分だけ指定どおりになる（余白 3mm なら 177mm・右 1mm カット）

切る側（右のみ）の考え方は、後で見直します。

## 公開（GitHub Pages）

ビルドが無いので、GitHub Actions は不要です。ブランチをそのまま公開します。

1. `main` ブランチを push する
2. リポジトリの Settings → Pages → Build and deployment → Source を **Deploy from a branch** にし、
   Branch を `main` / `/ (root)` にして Save する
3. 1〜2 分待つと `https://<ユーザー名>.github.io/cigar-box-design-simulator/` で使えます（Pages の画面に URL が出ます）

- `.nojekyll`（空のファイル）は、GitHub Pages に Jekyll による変換をさせないために置いています。消さないでください
- 公開リポジトリなら無料で使えます（非公開リポジトリの Pages は有料プランが必要です）
- 更新するときは `main` に push するだけです。数分で反映されます
- 画像はブラウザ内でしか処理されず、サーバーには送られません
- 依頼文に入る URL は、開いているページの URL から作られるので、公開後は公開 URL になります
